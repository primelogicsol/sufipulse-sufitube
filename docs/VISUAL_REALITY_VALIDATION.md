# VISUAL REALITY VALIDATION

## Phase 14 — Rendered Screen Audit

This document acts as the visual validation manifest for the 5 prototype screens. The primary strategic shift implemented in this phase is the **Unified Knowledge Graph Language**.

---

## 1. The Unified Knowledge Graph Language
**Risk Identified:** Fragmented visual artifacts (Influence Constellation, Concept Orbit, etc.) threatened to break the platform's institutional coherence.
**Solution:** A single, unified visual geometry has been established for all graph interactions.

* **Nodes:** Sharp, consistent geometric points (e.g., rigid circles with identical stroke weights).
* **Edges:** Hairline `#D4D4D8` (stone-300) connectors, glowing `#1A1815` (near black) on hover.
* **Typography:** `10px` mono-spaced sans for all node labels.
* **Variants:**
  1. *Influence View (Writers):* Radiating outward from the center.
  2. *Relationship View (Songs):* Symmetrical, interconnected web.
  3. *Concept View (Concepts):* Circular, orbital alignment.
  4. *Transmission View (Singers):* Top-to-bottom waterfall lineage.
* **Result:** The user learns how to read the graph *once*, and applies that literacy across the entire institution.

## 3. The Responsive Matrix (Device Validation)
* **Desktop:** Maximizes deep architectural whitespace. Allows persistent sticky side-columns (e.g., Focal Entities, Concept Networks).
* **Tablet:** Drops sticky side-columns into inline, full-width horizontal scrolling galleries. Graph views convert to tap-friendly interactive panels.
* **Mobile:** Heavy graphs abstract entirely into vertical "Lineage Matrices" (accordions) to prioritize raw reading and tap navigation. Enlarged "Next Discovery" buttons catch the user at the bottom of the scroll.
