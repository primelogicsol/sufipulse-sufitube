# COMPONENT CONSTITUTION

## Phase 10.2 — The UI Constraint Engine

To prevent the degradation of the institutional aesthetic, UI components are strictly limited. Every React/Figma component must belong to one of five approved archetypes.

---

### The 5 Component Archetypes
1. **Exhibit Component:** Elements that introduce or frame an entity (e.g., Hero titles, atmospheric headers).
2. **Knowledge Component:** Elements delivering direct answers or narratives (e.g., Text blocks, Canonical Summaries).
3. **Evidence Component:** Elements displaying verification (e.g., Citation plaques, Source trails).
4. **Discovery Component:** Elements driving navigation (e.g., Knowledge Artifact Cards, Discovery Trails).
5. **Research Component:** Elements facilitating deep exploration (e.g., Toggles, Question Banks, Timelines).

*If a proposed component does not fit into one of these five archetypes, it is instantly rejected.*

---

### The Component Ban List
The following UI patterns destroy institutional credibility and are **permanently prohibited**:
* ❌ KPI Cards or Vanity Statistic Widgets
* ❌ Generic SaaS Dashboards
* ❌ Bootstrap Panels or Admin Cards
* ❌ Marketing Banners or "Call to Action" pop-ups
* ❌ Carousels used merely for decoration
* ❌ Floating Action Buttons (FABs)
* ❌ Decorative Mystical Clichés (generic crescent moons, stock imagery of dervishes)

---

### Required Core Components
The interface will be assembled exclusively from these highly refined building blocks:
* **Canonical Answer Artifact:** The definitive truth block.
* **Knowledge Artifact:** The interactive card representing an entity.
* **Relationship Constellation:** The interactive graph visualizer.
* **Evidence Archive:** The citation plaque.
* **Question Intelligence Block:** The inquiry and answer module.
* **Discovery Trail:** The contextual breadcrumb/next-step engine.
* **Timeline Artifact:** The historical scrubber.
* **Influence Artifact:** The master/disciple network visualizer.

### The Critical Design Test
Before any screen is approved for implementation, it must pass this test:
*Remove all logos, titles, and overt branding from the screen. Does it still feel undeniably like SufiPulse?* 
If it defaults to looking like a generic blog or Wikipedia, the component architecture has failed.
